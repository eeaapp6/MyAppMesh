# MyAppMesh
A mesh generation software based on FastCAE base and framework

## Development handoff

- Feature specification and implementation planning are maintained under [`specs/001-appmesh-core-functions/`](specs/001-appmesh-core-functions/).
- Spec Kit project workflow files are maintained under [`.specify/`](.specify/).
- The large FastCAE `Tools/` bundle is delivered separately. See [`dependencies/FastCAECodeBase/TOOLS.md`](dependencies/FastCAECodeBase/TOOLS.md) before configuring the project.
- Build prerequisites and validation commands are documented in [`quickstart.md`](specs/001-appmesh-core-functions/quickstart.md).
